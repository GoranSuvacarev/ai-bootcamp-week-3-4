# Asset attribution

This project uses a selected 32x32 subset of user-owned asset packs by LimeZu:

- **Modern Exteriors – RPG Tileset**: level tiles and character sprites.
- **Modern User Interface**: UI Style 2 panel and icon art.

The source packs are not included in full. The Modern UI license requires credit and
prohibits resale or redistribution of the asset pack. Preserve this attribution and
the pack-license terms when publishing or distributing the project.
